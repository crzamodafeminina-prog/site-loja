# CRZA — loja

Projeto Vite + React da CRZA.

A estrutura é intencionalmente simples para facilitar o deploy na Vercel.

## Estrutura

- `index.html`
- `main.jsx`
- `App.jsx`
- `index.css`
- `package.json`
- `vite.config.js`
- `tailwind.config.js`
- `postcss.config.js`
- `vercel.json`

## Deploy

Na Vercel, o diretório raiz do projeto deve ser a pasta que contém diretamente o `package.json` e o `index.html`.

Comandos:

`npm install`

`npm run build`
